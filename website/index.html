Engineered for Latency-Critical Production

Every subsystem is built from the ground up for sub-millisecond responsiveness, memory safety, and complete data resilience.

DAG

Directed Acyclic Graph (DAG)

Compiles multi-track timeline states into an immutable topological render graph. Content-addressed hashing eliminates redundant GPU shader execution.

48k

48 kHz Low-Latency WASAPI

Native 48,000 Hz 32-bit floating-point audio engine. Dynamic linear resampling, automated clip volume and stereo pan, 3-band EQ, and lookahead tanh soft limiter.

KEY

Keyframe Automation

Five interpolation curves (Linear, Ease In, Ease Out, Ease In-Out, Hold) driving spatial transforms, layer opacity, speed remapping, and audio volume envelopes.

MSK

Geometric Shape Masking

Pixel-accurate Rectangle, Ellipse, Linear Gradient, and Vignette mask generators with normalized feather radius and alpha inversion.

WAL

CRC32 Write-Ahead Log

Append-only binary journal (.reddart.wal) recording all timeline mutations with CRC32 checksums. Automatic torn-write truncation guarantees zero project corruption.

GPU

Hardware Video Export

Automatic discovery for NVIDIA NVENC, AMD AMF, Intel QuickSync, and Apple VideoToolbox with software libx264/libx265 fallback.
