# Reddart Feature Implementation & Verification Matrix (v1.0.0 Production)

## Classification Schema

Each advertised product feature is audited against actual working code, user-visible UI entry points, automated regression test coverage, and remaining technical limitations:

1. **Implemented and Verified in Desktop Workflow**: Fully operational in GUI studio or CLI, covered by automated integration tests, and verified.
2. **Partially Implemented**: Core engine logic exists and functions in export or backend pipelines, but UI surface or interactive tooling is currently incomplete.
3. **Experimental**: Underlying algorithms or crate implementations exist, but are intentionally gated, deactivated in production desktop workflows, or deferred.
4. **Not Implemented**: Planned roadmap item not yet present in the codebase.

## Public Documentation Alignment

Public-facing documentation (`README.md`, `ready_to_use/windows/manifest.json`, and `docs/RELEASE_NOTES_AND_LIMITATIONS.md`) reflects these verified capabilities:
1. **Nested Compound Clips**: Fully implemented in core and render graph via PR #8; sub-sequences can be placed across multi-track timelines.
2. **Multi-Channel Surround Audio (5.1 / 7.1)**: Fully implemented via PR #9; multichannel track layouts, 2D spatial panner, and ITU-R BS.775 downmixing operational.
3. **AI Auto-Reframe & Saliency Tracking**: Fully operational in Clip Inspector and export pipeline via PR #12; 9:16 vertical reels, 1:1 square, and 4:5 social aspect ratios with smooth camera panning.
4. **Optical Flow Retiming**: Cinema-grade motion-compensated interpolation operational via PR #13.
5. **Real-Time Spectrum & Parametric EQ**: Live 60 FPS FFT frequency visualizer and 4-band interactive equalizer operational via PR #14.
6. **Core Engine Hardening**: All project edits verified reversible via CommandHistory (PR #17), atomic WAL batching with failure rollback (PR #18), non-blocking asynchronous decode queues (PR #19), lock-free real-time audio playback (PR #20), and GPU multi-track ping-pong preview compositing (PR #21).
7. **Text & Subtitle Generator**: Export/overlay-rendered, noting that rich in-monitor WYSIWYG typography is targeted for v1.1. Workaround: transparent PNG overlays.
