========================================================================
🎬 REDDART — ZERO-LAG NATIVE VIDEO EDITOR (WINDOWS v0.1.0)
========================================================================

Reddart is a high-performance, subscription-free, on-device video editor
built with a shared native Rust core ("Path C"), hardware-accelerated WGSL
shaders, and an adaptive quality governor.

🚀 HOW TO RUN:
Double-click `Reddart.exe` to launch the editor immediately.
No installation or runtime dependencies required.

✨ FEATURES INCLUDED:
- Multi-track timeline (Video, Audio, Subtitle Text)
- Hardware GPU Compositor with 60 FPS live preview monitor
- Curated 3D LUT Color Grading presets (Teal & Orange, Warm Sunlight, Vintage Film, B&W)
- Support for external .cube 3D LUT import
- Geometric Shape Masks (Rectangle, Ellipse, Gradient, Vignette) with edge feathering
- Chroma Keying (Green screen) with green spill suppression
- On-device speech-to-text Subtitles / Auto Captions (Whisper)
- On-device Audio Denoise (spectral gating filter)
- Camera Motion Stabilization and Auto Reframe (9:16 vertical)
- Curated Starter Templates (Reels/TikTok Beat Cut, Cinematic Vlog, Social Square)
- Multi-stage parallel export with calibrated presets (YouTube 1080p/4K, TikTok 9:16, Instagram 1:1)

⌨️ KEYBOARD SHORTCUTS:
- Space               : Play / Pause
- S                   : Split clip at playhead
- Del / Backspace     : Delete selected clip
- Ctrl + Z            : Undo
- Ctrl + Y            : Redo
- Ctrl + E            : Open Export dialog
- Left / Right Arrow  : Step 1 sec back / forward
- Shift + Left/Right  : Step 1 frame (33.3ms) back / forward
- F1 or Shift + ?     : Open Shortcuts & Help dialog
